# python313-digest

Handout digest of the official "What's New in Python 3.13" release notes for a
study group's Python 3.13 unit.

## What is this repository?

This repository collects a distilled digest of the CPython 3.13 release notes
(https://docs.python.org/3/whatsnew/3.13.html). It is intended as a study handout
covering the major highlights, notable deprecations, and the source page used.

## Digest file

- [python-313-release-notes-digest.md](python-313-release-notes-digest.md) —
  the main digest with sections: **Highlights** (bulleted, with PEP numbers
  where cited), **Notable deprecations**, and a **Source** line naming the page
  actually read (https://docs.python.org/3/whatsnew/3.13.html).

## Branches

- `python-313-digest` — branch that adds the digest file and updates this README;
  merged into `main` via a squash-merged pull request.
